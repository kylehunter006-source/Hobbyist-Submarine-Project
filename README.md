# Hobbyist-Submarine-Project
  This is a personal project initially created as a method to implement the camera the I made. It has since changed into a project that has received multiple iterations all of which has nothing to do with the implementation of the camera. The design of the sub has had multiple overhaul as the physical assembly has been either insufficient or impossible to create even when considering 3d printing which would allow for the most freedom when designing.

  The realistic and non-realistic folders were created realizing the sub doesn't need to have reduced noise, cavitation and tip-losses. So the sub was split into 2 pathway being a traditional single turbine sub and a unrealistic sub built to test my design ability.
